# saucedemo-manual-qa
SauceDemo — Manual QA Testing

О проекте
Учебный проект по ручному тестированию интернет-магазина SauceDemo.

Цель тестирования
Проверить основные пользовательские сценарии:
Авторизация с корректными и некорректными данными
Проверка входа с пустыми полями
Добавление и удаление товара из корзины
Сортировка товаров по цене
Оформление заказа и проверка итоговой суммы

Тестовое окружение
Операционная система: Windows 11
Браузер: Google Chrome
Тестовый аккаунт: standard_user
Тип тестирования: ручное функциональное тестирование

Результаты тестирования
Выполнено 7 тест-кейсов:
6 — Passed
1 — Passed with observation

Во время проверки замечено, что изображение товара не отображается в корзине и на странице обзора заказа. Перед регистрацией окончательного дефекта необходимо подтвердить ожидаемое поведение.

Проверена сумма заказа:
Стоимость товара: $29.99
Налог: $2.40
Итоговая сумма: $32.39

Ограничения
Тестирование выполнено вручную в одном браузере. Автоматизированные тесты не запускались.
